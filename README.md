# Open-CV-Projects

A collection of Python-based Computer Vision, AI Assistant, Automation, and Vision-Control projects.

This repository brings together multiple independent projects focused on practical applications of **Computer Vision, AI, Image Processing, Gesture Control, Face Detection, Eye Tracking, and Automation**.

---

## 🚀 Projects

| Project | Description |
|---|---|
| 🤖 `AI_ASSISTANT` | AI assistant related project and automation functionality. |
| 👁️ `EYES_DETECT` | Eye detection / eye-related computer vision project. |
| 🎯 `EYE_CONTROL` | Eye-based control and interaction project. |
| 🙂 `FACE_DETECT` | Face detection using computer vision techniques. |
| ✋ `HAND_GESTURE_CONTROL.py` | Control applications using hand gestures. |
| 😄 `SMILE_PIC` | Smile detection / smile-based image functionality. |
| 😊 `SMILE_RECO` | Smile recognition related computer vision project. |
| 🎥 `VIDEO_DOWNLOADER` | Video downloading utility. |
| 🔊 `VOLUME_CONTROL` | System volume control using computer vision / gesture interaction. |
| 💬 `WHATSAPP_MSG_SENDER` | WhatsApp message automation utility. |

> Each project is maintained separately inside its respective directory/file.

⚙️ Installation
1. Clone the repository
git clone https://github.com/ItsRehmanDev/OPEN-CV-PROJECTS.git
2. Navigate into the project
cd OPEN-CV-PROJECTS
3. Create a virtual environment

Windows:

python -m venv venv
venv\Scripts\activate

Linux / macOS:

python3 -m venv venv
source venv/bin/activate
4. Install dependencies

If a project contains a requirements.txt file:

pip install -r requirements.txt

Otherwise, install the dependencies specified by the individual project.

▶️ Running a Project

Each project may have its own entry point and requirements.

For example:

python HAND_GESTURE_CONTROL.py

For directory-based projects, first enter the required directory:

cd FACE_DETECT

Then run the project's main Python file.

Check the source files of the individual project for project-specific setup instructions.
